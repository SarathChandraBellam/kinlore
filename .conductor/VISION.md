# Kinlore (product vision, from SARATH)
Your family's stories, in their own voices. Open-source desktop app that helps families keep stories told by elders.
Status: early design; app not built yet.
What it does: curious AI interviewer with follow-ups; imports WhatsApp voice notes / home videos / old recordings, transcribes, diarizes speakers, turns them into stories; family can ask questions and hear the real clip where it was answered, never invents memories; ask one person or the whole family, show where memories differ; keepsakes, family cookbook told aloud, family timeline, sealed recordings for future events; Telugu, Hindi, Tamil, English incl. code-mixing.
Beliefs: everything local, no account/server/subscription; real recordings first, generated voice optional, off by default, consented, labeled; consent built in; open source + open portable archive format, models swappable; optional user API keys kept in OS keychain, show exactly what leaves the computer.
Roadmap: 1 Record and listen (interviews, family questions, real-clip answers, keepsakes, English+Telugu). 2 Understand (WhatsApp/video import, adaptive interviewer, ask whole family, timeline, recipes, BYO keys). 3 Extend (sealed recordings, opt-in style voice, encryption with recovery key, more languages).
